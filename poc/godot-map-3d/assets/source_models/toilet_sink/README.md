# CC0 toilet and sink source

`toilet_sink_source.glb.gz` contains only `Toilet_Elongated_C` and `Sink_B`, selected from [Toilets](https://opengameart.org/content/toilets) by loafbrr_1. The source asset is released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

The two nodes were moved into a compact toilet/sink arrangement with `tools/curate_toilet_glb.py`; no wall, background, or helper plate is included in the scene.
